# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-01-20

### Added
- Initial release of VSM Rate Limiter
- Token bucket algorithm implementation
- Adapters for ExRated and Hammer libraries
- VSM subsystem-based rate limiting (S1-S5)
- Algedonic signaling system for critical alerts
- Variety attenuation based on Ashby's Law
- Comprehensive telemetry integration
- Full test suite
- Documentation and examples
